# wage

Dieses Repository enthält zwei Projektbereiche:

- `wage-esp32/` – ESP32-Waage (PlatformIO-Projekt)
- `raspberry-pi/` – Platzhalter für späteres Backend/Webinterface/Datenbank

Hinweis:
- Die Waage läuft aktuell standalone auf dem ESP32.
- Der Raspberry-Pi-Code wird separat in `raspberry-pi/` entwickelt.
